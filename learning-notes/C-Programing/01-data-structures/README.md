# Data Structures

## Problems

### 1. Singly Linked List Operations
**File:** `linked_list.c`
- Implement reverse, detect cycle, find middle element
- Memory-efficient implementation

### 2. Stack Using Array
**File:** `stack.c`
- Fixed-size stack with overflow/underflow handling
- Optimize for embedded systems

### 3. Circular Buffer (Ring Buffer)
**File:** `circular_buffer.c`
- FIFO buffer for embedded communication
- Thread-safe operations

### 4. Binary Search Tree
**File:** `bst.c`
- Insert, delete, search operations
- Iterative implementations preferred

### 5. Hash Table
**File:** `hash_table.c`
- Simple hash function
- Collision handling (chaining or open addressing)
